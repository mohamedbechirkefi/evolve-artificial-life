# experiments/

`configs/` holds run configurations. `EXP-001.json` to `EXP-003.json` encode the draft protocol v0.1 (label `confirmatory`; `run` refuses them until the owner freezes the protocol). `smoke.json` (protocol B.9 smoke matrix) and `pilot.json` (all planned arms at planned budgets, 10 seeds) are exploratory and use the exploratory test pool (D-006). The registered experiments, their protocols and reports live in `research/experiments/EXP-NNN/`.
